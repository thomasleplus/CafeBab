# xbee

Digi X-CTU configuration profiles (`.pro`) for the XBee radio modules used by
the project. Load one in X-CTU to flash the matching radio settings.

- `cafe.pro`, `babe.pro` — profiles for the coordinator/end-device radios.
- `default.pro` — a baseline/factory profile.
- `upgrade.pro` — firmware/settings upgrade profile.
