# utils

Third-party drivers and tools needed to set up the XBee/USB hardware on a
developer machine. These are vendored binaries, **not** maintained here.

- `XCTU_*.exe` — Digi's X-CTU configuration tool (Windows installer).
- `ftdi_WindowsVistaDrivers.zip`, `pkgu_*_drivers*` — FTDI/USB serial drivers
  for Windows, macOS and Linux.

Prefer downloading current versions from the vendors when possible.
